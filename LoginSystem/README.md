# Java 登录系统

一个简单而完整的Java登录系统，提供用户注册、登录、注销等功能。

## 功能特性

- 🔐 用户注册和登录
- 🔒 密码SHA-256加密
- ✅ 输入验证（用户名、密码、邮箱格式）
- 👤 用户信息管理
- 🕒 登录时间记录
- 🖥️ 控制台交互界面
- ✨ 完整的单元测试

## 快速开始

### 环境要求

- Java 8 或更高版本
- Maven 3.6 或更高版本

### 编译和运行

1. **克隆或下载项目到本地**

2. **编译项目**
   ```bash
   cd LoginSystem
   mvn compile
   ```

3. **运行应用程序**
   ```bash
   mvn exec:java
   ```
   
   或者直接运行编译后的类：
   ```bash
   mvn compile exec:java -Dexec.mainClass="com.login.ui.ConsoleLoginApp"
   ```

4. **运行测试**
   ```bash
   mvn test
   ```

### 使用说明

1. **启动程序后，您会看到主菜单：**
   ```
   =================================
        欢迎使用登录系统
   =================================
   
   请选择操作：
   1. 登录
   2. 注册
   3. 退出
   ```

2. **登录：**
   - 选择选项 1
   - 输入用户名和密码
   - 登录成功后可查看个人信息或注销

3. **注册：**
   - 选择选项 2
   - 按提示输入用户名（不能重复）
   - 输入密码（至少6位）
   - 输入有效的邮箱地址

4. **登录后功能：**
   - 查看个人信息（用户名、邮箱、注册时间、最后登录时间等）
   - 注销登录
   - 退出程序

## 核心类说明

### User.java
用户模型类，包含：
- 用户名、密码哈希、邮箱
- 创建时间、最后登录时间
- 账户状态
- 密码加密和验证方法

### LoginService.java
核心业务逻辑类，提供：
- 用户登录验证
- 用户注册功能
- 输入验证
- 返回详细的操作结果

### UserDao接口 和 UserDaoImpl
数据访问层：
- 定义用户数据操作接口
- 提供内存存储实现
- 支持用户的增删改查操作

### ConsoleLoginApp.java
控制台用户界面：
- 提供友好的交互界面
- 处理用户输入
- 显示操作结果

## 安全特性

1. **密码安全：**
   - 使用SHA-256算法对密码进行哈希加密
   - 不存储明文密码

2. **输入验证：**
   - 用户名不能为空且不能重复
   - 密码长度至少6位
   - 邮箱格式验证

3. **错误处理：**
   - 详细的错误信息提示
   - 安全的错误消息（不泄露敏感信息）

## 扩展建议

1. **数据持久化：**
   - 可以将UserDaoImpl替换为数据库实现
   - 支持MySQL、PostgreSQL等数据库

2. **Web界面：**
   - 可以添加Spring Boot集成
   - 提供REST API接口

3. **更强的安全性：**
   - 添加盐值(Salt)增强密码安全性
   - 实现JWT Token认证
   - 添加登录失败次数限制

4. **更多功能：**
   - 密码重置功能
   - 用户权限管理
   - 登录日志记录
